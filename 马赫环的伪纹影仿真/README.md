# 马赫环伪纹影仿真 - 2D可压缩流模拟

## 🎯 项目概述
这是一个完整的计算流体力学(CFD)仿真程序，用于模拟从拉瓦尔喷管喷出的欠膨胀超声速射流中的马赫环（激波钻石）现象。程序实现了二维可压缩欧拉方程的数值求解，并生成高质量的伪纹影可视化动画。

## ✨ 核心特性
- **完整的CFD求解器**：实现HLLE格式(Harten-Lax-van Leer-Einfeldt)求解二维欧拉方程
- **自适应时间步长**：基于CFL条件的物理时间驱动模拟
- **拉瓦尔喷管几何**：参数化的收缩-扩张喷管形状
- **激波自动检测**：实时识别并标记马赫环位置
- **高性能计算**：使用NumPy向量化操作，float32数据类型优化内存使用

## 🔬 物理原理
控制方程
程序求解无量纲形式的二维欧拉方程：

∂U/∂t + ∂F/∂x + ∂G/∂y = 0

其中守恒变量：

U = [ρ, ρu, ρv, E]^T

数值方法
空间离散：有限体积法

数值通量：HLLE近似黎曼求解器

时间推进：显式时间积分，自适应时间步长

边界条件：入口超音速、出口无反射、壁面滑移

欠膨胀射流物理
喷管出口压力 > 环境压力

产生交替的膨胀扇和激波

形成周期性马赫环结构

激波钻石间距与压力比相关

## 📈 结果分析
马赫环特征
位置：喷管下游的周期性激波结构

间距：随下游距离略微增加

强度：激波强度逐渐减弱

数量：取决于计算域长度和压力比

典型观察值

马赫环数量	8-12个	在默认Lx=160.0下

## 🔍 调试和优化
### 常见问题及解决
计算不稳定

```python
# 降低CFL数
CFL = 0.45
# 或减小时间步长
T_END = 60.0  # 减少总时间
```
内存不足

```python
# 降低网格分辨率
NX, NY = 360, 120
# 使用float32数据类型（默认）
```
马赫环检测不准确

```python
# 调整检测参数
PEAK_THR_REL = 0.65      # 提高阈值
PEAK_MIN_DIST_FRACTION = 0.03  # 减小最小距离
```
性能优化技巧
```python
# 1. 使用适当网格：720×240是平衡点
# 2. 调整总时间：T_END=60.0可更快看到结果
# 3. 降低输出帧率：OUTPUT_FPS=10
```
