# 视频标志物跟踪分析系统

## 🎬 项目概述
一个专业的视频运动分析系统，基于计算机视觉技术实现高精度的标志物跟踪、运动学分析和阻尼系数计算。适用于物理实验、生物力学、工程测试等多个领域。

## ✨ 核心特性
- **多算法跟踪**：Lucas-Kanade光流法 + 特征点跟踪
- **智能标定**：像素到物理单位的精确转换
- **运动分析**：位移、速度、加速度完整计算
- **阻尼拟合**：自动阻尼系数计算和拟合评估
- **交互修正**：实时重新标记和跟踪校正
- **专业报告**：自动生成Excel报告和图表

## 🔬 分析方法

### 运动学参数计算
```python
# 位移计算
displacement_x = x_cm - x_cm[0]
displacement_y = y_cm - y_cm[0]
displacement_mag = np.sqrt(displacement_x**2 + displacement_y**2)

# 速度计算（中心差分）
vx = np.gradient(x_cm, time)
vy = np.gradient(y_cm, time)
v_mag = np.sqrt(vx**2 + vy**2)

# 加速度计算
ax = np.gradient(vx, time)
ay = np.gradient(vy, time)
a_mag = np.sqrt(ax**2 + ay**2)
```

### 数据平滑处理
```python
# 移动平均平滑
def smooth_positions(positions, window_size=5):
    smoothed = []
    for i in range(len(positions)):
        start = max(0, i - window_size // 2)
        end = min(len(positions), i + window_size // 2 + 1)
        smoothed.append(np.mean(positions[start:end]))
    return smoothed
```

### 阻尼系数分析流程
1. 选择要分析的标志物

3. 自动拟合阻尼指数衰减曲线
4. 计算阻尼系数b和平衡位置y0
5. 评估拟合优度R²

## 🔍 故障排除

### 常见问题及解决方案

#### 问题1：跟踪点丢失
```
症状：跟踪点突然消失或跳到错误位置
原因：快速运动、遮挡、光照变化
解决：
1. 降低跟踪速度（减小最大位移）
2. 增加特征点数量
3. 使用重新标记功能修正
```

#### 问题2：坐标标定误差
```
症状：物理单位计算结果不合理
原因：标定点选择不准确或距离测量错误
解决：
1. 重新标定，选择清晰的标志点
2. 使用已知尺寸的标定物体
3. 多次测量取平均值
```

#### 问题3：阻尼拟合失败
```
症状：阻尼系数计算为None或R²很低
原因：数据噪声大或选择的时间段不合适
解决：
1. 增加数据平滑窗口
2. 选择明显的衰减阶段
3. 手动检查位移曲线
```

#### 问题4：内存不足
```
症状：程序崩溃或变慢
原因：视频太大或跟踪点太多
解决：
1. 降低视频分辨率
2. 减少跟踪点数量
3. 使用跳帧处理
```

## 📚 理论背景

### 光流法原理
```
亮度恒定假设：I(x,y,t) = I(x+dx, y+dy, t+dt)
泰勒展开：I(x+dx, y+dy, t+dt) ≈ I(x,y,t) + I_x dx + I_y dy + I_t dt
光流方程：I_x u + I_y v + I_t = 0
```

### 阻尼振动理论
```
运动方程：m d²x/dt² + c dx/dt + kx = 0
阻尼系数：ζ = c / (2√(mk))
衰减规律：x(t) = A e^(-ζω₀t) cos(ω_d t + φ)
```

### 误差分析
```python
# 主要误差来源
1. 标定误差：±1-2%
2. 跟踪误差：±0.5-2像素
3. 数值微分误差：取决于平滑方法和数据质量
4. 拟合误差：取决于数据噪声和模型匹配度
```

## 🚧 限制和注意事项

### 技术限制
1. **光照敏感性**：强烈光照变化影响跟踪精度
2. **遮挡问题**：物体被遮挡会导致跟踪失败
3. **运动模糊**：快速运动导致图像模糊
4. **计算资源**：高清长视频需要大量内存

### 使用建议
1. **视频质量**：使用高帧率、高分辨率的视频
2. **照明条件**：保持均匀稳定的照明
3. **标志物设计**：使用高对比度、独特的标志物
4. **标定精度**：精确测量实际距离
5. **验证结果**：与手动测量或理论值对比
