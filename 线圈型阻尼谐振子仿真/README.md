# 电磁阻尼仿真程序

这是一个用于模拟弹簧-磁铁-线圈系统中电磁阻尼效应的Python程序。该系统由一个垂直弹簧悬挂的磁铁和固定的线圈组成，当磁铁在线圈内运动时，会产生感应电流，从而产生阻尼力。

## 物理模型

### 系统描述
- 质量块（磁铁）通过弹簧悬挂
- 固定线圈包围磁铁运动路径
- 线圈可连接外部电阻或开路
- 系统在重力作用下垂直振动

### 微分方程
系统由三个耦合的常微分方程描述：

1. **位置方程**: `y' = v`
2. **速度方程**: `v' = (-k*y + N*i*dphi_dz(y))/m`
3. **电流方程**: `i' = ( -R_total*i - N*dphi_dz(y)*v )/L`

其中：
- `y`: 磁铁位置
- `v`: 磁铁速度
- `i`: 线圈电流
- `m`: 质量
- `k`: 弹簧常数
- `N`: 线圈匝数
- `dphi_dz(y)`: 磁链梯度
- `R_total`: 总电阻（线圈电阻 + 外部电阻）
- `L`: 线圈电感

### 磁链计算
单匝线圈的磁链梯度使用偶极子近似计算：
```
dphi_dz = -3 * μ₀ * m_dipole * a² * z / (2 * (a² + z²)^(2.5))
```
其中：
- `μ₀`: 真空磁导率
- `m_dipole`: 磁铁偶极矩
- `a`: 线圈半径
- `z`: 磁铁相对于线圈中心的位置

## 功能特性

### 1. 数值求解器
- 支持多种求解方法：
  - RK4（四阶龙格-库塔法）- 默认
  - Numba加速的RK4（可选，需安装numba）
  - SciPy ODE求解器（可选，需安装scipy）
- 自适应时间步长选择
- 支持进度显示和用户中断

### 2. 可视化输出
- **静态图像**:
  - 位置-时间图（完整和缩放）
  - 速度-时间图（完整和缩放）
  - 电流-时间图（完整和缩放）
  - 能量转换图
  - 相图（位置-速度）
  - 电磁耦合诊断图

- **动画**:
  - 左侧：物理场景可视化
  - 右侧：2×3实时图表（位置、速度、电流、能量、相图、电磁耦合）
  - 输出为GIF格式

### 3. 图形用户界面
- Tkinter GUI
- 参数实时调整
- 进度条和剩余时间估计
- 输出日志显示
- 生成的GIF动画预览

### 4. 性能优化
- Numba JIT编译加速（可选）
- 计算缓存机制
- 快速模式（降低精度提高速度）
- 进度条支持（tqdm或简单控制台版本）

## 使用方法

### 命令行模式
```bash
# 使用默认参数运行
python 电磁阻尼.py

# 启动GUI模式
python 电磁阻尼.py --gui
```

### GUI模式
1. 启动GUI：`python 电磁阻尼.py --gui`
2. 在左侧面板调整参数
3. 点击"运行模拟"开始计算
4. 可在运行时点击"停止模拟"中断
5. 结果会在右侧显示，包括：
   - 模拟输出日志
   - 生成的GIF动画

### 主要参数说明

#### 机械参数
- **质量 m** (kg): 磁铁质量
- **弹簧常数 k** (N/m): 弹簧刚度
- **初始位移 y0** (m): 初始位置偏移
- **初始速度 v0** (m/s): 初始速度

#### 电磁参数
- **磁偶极矩 m_dipole** (A·m²): 磁铁磁矩
- **线圈匝数 N_turns**: 线圈总匝数
- **线圈半径 a** (m): 线圈内半径
- **电感 L_coil** (H): 线圈电感
- **线圈电阻 R_coil** (Ω): 线圈内阻

#### 模拟设置
- **模拟时间 t_end** (s): 总模拟时间
- **外部电阻 Rext**: 逗号分隔的外部电阻值，用"open"表示开路
- **帧率 fps**: 动画帧率
- **缩放时间 t_zoom** (s): 静态图的缩放区域

#### 性能选项
- **快速模式**: 降低精度提高计算速度
- **使用Scipy ODE求解器**: 使用SciPy的求解器（如果可用）

## 物理现象演示

### 阻尼效应变化
- **开路状态** (`Rext=∞`): 纯机械振动，无电磁阻尼
- **小电阻状态**: 强阻尼，能量快速转化为热能
- **中电阻状态**: 中等阻尼，部分能量转化为电能
- **临界阻尼**: 电阻匹配时达到最优阻尼

### 能量转换
- 机械能（动能 + 势能）→ 电能（线圈电感）→ 热能（电阻发热）
- 总能量守恒（忽略数值误差）

## 故障排除

### 常见问题
1. **模拟速度慢**:
   - 启用快速模式
   - 安装numba加速
   - 减少模拟时间或增加时间步长

2. **内存不足**:
   - 减少模拟步数
   - 启用快速模式

3. **动画生成失败**:
   - 确保Pillow库已安装
   - 检查磁盘空间
   - 减少动画帧数

4. **GUI无响应**:
   - 确保在主线程中运行GUI
   - 检查是否有其他进程占用资源
