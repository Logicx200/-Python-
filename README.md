# 基于Python的工具箱

这是一个集成了多个Python实用工具的仓库，涵盖物理仿真、计算机视觉、文档处理、流体力学等多个领域。每个工具都是独立且功能完整的应用程序。
## ❗重要提示
感谢您关注本项目！本项目中的程序仅限于个人交流学习用途，用于公开场合之前请邮箱联系作者。由于个人精力有限，部分工具可能存在功能不完善或未完成的情况。如果您有任何建议或想要贡献代码，请随时提交Pull Request或开Issue讨论。

## 📦 工具列表

### 1. 🎬 视频标志物跟踪分析系统
**专业视频运动分析工具**
- 多算法跟踪（Lucas-Kanade光流法 + 特征点跟踪）
- 智能像素到物理单位标定
- 完整的运动学分析（位移、速度、加速度）
- 阻尼系数自动计算和拟合
- 交互式跟踪修正功能
- 自动生成Excel报告和图表

### 2. 🔄 电磁阻尼仿真程序
**弹簧-磁铁-线圈系统电磁阻尼仿真**
- 耦合常微分方程数值求解
- 支持多种求解方法（RK4、Numba加速、SciPy ODE）
- 完整的物理模型（磁链计算、电磁感应）
- 实时参数调整GUI界面
- 多种阻尼状态模拟（开路、临界阻尼等）
- 丰富的可视化输出（静态图 + 动画）

### 3. 🔄 双摆模型仿真 - 混沌动力学可视化
**经典混沌系统数值模拟**
- 高精度数值积分（SciPy RK45方法）
- 多系统并行模拟（100个微扰双摆）
- 四维相空间可视化（4个投影视图）
- "蝴蝶效应"直观展示
- 高质量动画输出（MP4/GIF格式）
- 科学级计算精度（相对误差容限1e-8）

### 4. 🎯 马赫环伪纹影仿真 - 2D可压缩流模拟
**计算流体力学(CFD)仿真程序**
- HLLE格式求解二维欧拉方程
- 拉瓦尔喷管欠膨胀超声速射流模拟
- 自适应时间步长（基于CFL条件）
- 激波钻石（马赫环）自动检测
- 伪纹影可视化技术
- 高性能数值计算（NumPy向量化优化）

### 5. 🖼️ Markdown Base64图片上传工具
**Markdown图片管理专业工具**
- 智能Base64图片检测和提取
- 批量上传到SM.MS图床
- 图片预览和格式验证
- Base64格式自动修复
- API Token管理和配置持久化
- 详细的处理日志和错误报告

### 6. 📄 DOCX 转 Markdown 转换器
**文档格式转换工具**
- 现代化Tkinter GUI界面
- 完整中文界面支持
- 智能文档结构识别
- 支持图片处理（忽略或base64嵌入）
- 批量处理能力扩展
- 详细的转换日志

## 🚀 快速开始

### 环境要求
```bash
# Python 3.7+
# 安装核心依赖
pip install numpy matplotlib opencv-python pandas scipy pillow requests mammoth tqdm
```

### 各工具运行方式

1. **视频跟踪分析系统**
```bash
python "Tracker on Opencv.py"
```

2. **电磁阻尼仿真**
```bash
python "电磁阻尼.py" --gui  # GUI模式
python "电磁阻尼.py"        # 命令行模式
```

3. **双摆混沌仿真**
```bash
python "双摆.py"
```

4. **马赫环CFD仿真**
```bash
python mach_ring_sim.py
```

5. **Markdown图片上传工具**
```bash
python "Markdown Base64图片上传工具.py"
```

6. **DOCX转Markdown转换器**
```bash
python "DOCX 转 Markdown 转换器.py"
```

## 🔍 使用建议

### 硬件要求
- **处理器**：建议多核CPU（4核以上）
- **内存**：建议8GB以上（复杂仿真需要更多）
- **显卡**：集成显卡即可（部分可视化可受益于独立显卡）
- **存储**：SSD推荐，用于快速文件读写

### 软件环境
- **操作系统**：Windows 10/11, Ubuntu 18.04+, macOS 10.15+
- **Python版本**：Python 3.7 - 3.10（推荐3.8+）
- **包管理器**：pip 20.0+

### 最佳实践
1. **先测试后使用**：在小规模数据上测试配置
2. **参数调优**：根据硬件调整计算参数
3. **定期保存**：长时间计算时定期保存中间结果
4. **结果验证**：与理论值或其他工具对比验证

## 🚧 已知限制和注意事项

### 通用限制
1. **计算资源**：复杂仿真需要较多计算时间和内存
2. **精度限制**：数值计算存在舍入误差和截断误差
3. **模型简化**：物理模型可能忽略实际复杂因素
4. **硬件依赖**：某些功能需要特定硬件支持（如FFmpeg）

### 使用注意事项
1. **教学用途**：主要用于教学演示和科研探索

3. **参数敏感**：某些工具对参数设置较为敏感
